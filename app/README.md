# 网页看板

单页 HTML 看板，实时展示/控制小智·智家系统：

- 💡 设备控制（灯/窗帘/空调/插座，走网关 REST API）
- 🌡️ 环境感知（温度/湿度/空气质量/光照）
- 🎬 场景联动（睡眠/回家/离家/影院）
- 📋 运行日志
- 📚 NAS 知识中枢问答

## 使用

直接用浏览器打开 `dashboard.html`，或部署到任意静态服务器。

默认网关地址 `http://127.0.0.1:5000`（gateway.py），NAS 桥 `http://127.0.0.1:8080/query`（bridge.py）。
部署到其他机器时修改文件顶部 `GW` / `NAS` 常量。

> 生产环境建议将 CORS 与鉴权配置在网关侧（本示例为局域网演示简化版）。
