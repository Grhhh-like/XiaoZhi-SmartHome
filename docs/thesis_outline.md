## 创新点总结（可写入摘要/结论）

1. **双通道统一语音控制（参考米家模式）**：一套语音指令驱动 WiFi 联网（MQTT/HTTP）+ 蓝牙 BLE 双通道，兼容主流智能家居生态与自制低功耗节点
2. **MCP 协议驱动的工具链**：大模型通过 MCP 直接调用硬件工具，意图理解+参数抽取+状态回读闭环
3. **主动式智能家居**：从"被动应答"到"主动关怀"，规则引擎+习惯学习+异常检测
4. **私有数据知识中枢**：NAS+RAG，语音问答个人文档日程，数据主权归用户
5. **离线降级可靠性**：断网本地 BLE 直连兜底，提升系统鲁棒性
