# 稳定性设计文档（Stability）

> 目标：移动管家机器人 7×24 家庭运行不掉链子。
> 覆盖：通信可靠性、电源安全、运动安全、软件韧性、数据持久化、OTA。

---

## 1. 通信可靠性

### 1.1 WiFi 联网（MQTT/HTTP）掉线重连
| 机制 | 实现 |
|---|---|
| 指数退避重连 | 断连后 5s→10s→20s→…→120s 上限重试，恢复后重置 |
| 会话保留 | MQTT Clean Session=false + 遗嘱消息（LWT），网关能感知终端离线 |
| QoS | 控制指令 QoS=1（至少一次），网关幂等去重（request_id） |
| 断网降级 | `offline_is_active()` 检测断网 → 自动切离线命令词 + BLE 本地直连 |

### 1.2 蓝牙 BLE 节点
| 机制 | 实现 |
|---|---|
| 自动重连 | 终端 Central 周期扫描（30s 间隔），节点掉线后自动重连（最多 3 次/周期） |
| 连接保活 | 连接参数协商（30ms 间隔 × 6 超时），异常断开即时感知 |
| 节点发现 | 广播名 `XZ-<type>-<id>` 前缀过滤，注册表持久化（NVS） |
| 离线告警 | 节点失联 > 5min → 主动播报"XX 设备离线" |

### 1.3 NAS / 云端
- NAS Bridge 调用超时 5s，失败降级返回"NAS 暂不可用"，不阻塞语音主流程
- 云端大模型断连：保留本地唤醒 + 离线命令词兜底

## 2. 电源与能耗安全

| 机制 | 实现 |
|---|---|
| 电池监测 | INA226 采集电压/电流，终端圆屏显示电量 |
| 低电量保护 | < 20% 提醒充电，< 10% 自动停止移动（仅保留语音应答），< 5% 休眠 |
| 电机供电 | 12V 主电源独立 DC-DC，主控 5V/3.3V 隔离，防电机反电动势干扰 |
| 过流保护 | TB6612 自带限流；软件检测堵转电流 > 阈值 → 自动停止 |
| 睡眠调度 | 夜间/无人时段节点进入深睡（µA 级），周期唤醒上报 |

## 3. 运动安全（移动底盘）

| 机制 | 实现 |
|---|---|
| 看门狗 | 运动控制任务喂狗；失控（速度指令超时未确认）→ TWDT 复位 |
| 超声波急停 | 前方 < 20cm 立即停止，10cm 内禁行 |
| 堵转保护 | 编码器转速 < 期望 30% 持续 2s → 停转 + 播报"我卡住了" |
| 悬崖/边界 | IMU 俯仰角异常（>30°）→ 急停；可选下视传感器 |
| 跟随防丢 | 目标丢失 > 10s → 原地等待并播报"找不到你了" |
| 动作超时 | 所有 move 指令带超时（默认 30s 自动停止），防止命令丢失后乱跑 |
| 手动急停 | 物理急停按钮 + 语音"小智停下"（离线命令词，最高优先级） |

## 4. 软件韧性

| 机制 | 实现 |
|---|---|
| 双看门狗 | 任务看门狗（周期任务卡死检测）+ TWDT 硬件看门狗（30s） |
| 内存保护 | 周期任务栈 4096B；ESP_LOGV 级别默认关闭防刷屏 |
| 状态持久化 | NVS 保存：设备注册表、场景配置、用户偏好、主动规则开关 |
| 崩溃恢复 | 异常重启后自检：外设初始化失败 → 降级启动（跳过故障模块） |
| 防抖 | 主动提醒采用"连续 3 次采样确认"再播报，降低误报 |
| 日志轮转 | ESP-IDF 环形日志，异常前 100 条可回溯 |

## 5. OTA 升级

| 机制 | 实现 |
|---|---|
| 双分区 | OTA + Factory 分区，升级失败自动回滚 |
| 升级触发 | 网关 HTTP 下发 / 手机 APP 一键升级 |
| 升级校验 | 固件签名校验 + 版本号检查 |
| 安全窗口 | 升级期间禁用移动，升级后自动重启并验证 |

## 6. 可靠性测试清单（建议）

- [ ] WiFi 断开 10 分钟恢复 → 自动重连，期间离线指令可用
- [ ] BLE 节点断电 5 分钟恢复 → 自动重连且状态同步
- [ ] 低电量模拟 → 正确告警与降级行为
- [ ] 电机堵转 5s → 停止 + 告警
- [ ] 前方突然出现障碍 → 急停不撞
- [ ] 连续运行 72h → 无重启、无内存泄漏（esp_get_free_heap_size 监控）
- [ ] 主动提醒连续触发 → 无重复刷屏（防抖生效）
- [ ] 固件升级失败 → 自动回滚可用
- [ ] 断电重启 → 恢复断电前设备状态（NVS）
- [ ] 语音"小智停下"在移动中立即生效
