# 演示场景脚本

> 用于比赛路演 / 毕设答辩的完整演示脚本（约 5 分钟）

---

## 场景一：欢迎与体系介绍（30s）

> 小智，介绍一下你自己

**小智**："我是小智，你的家庭 AI 管家机器人。我能听懂你的话、自主移动到你身边，帮你控制全屋智能设备，主动关心你的生活，还能记住你的日程和知识。试试对我说：小智过来。"

## 场景二：语音召唤（40s）

> 小智，过来

- 差速底盘启动，移动到用户面前，圆屏显示开心表情
- 小智："我来啦！有什么可以帮你？"

**讲解点**：具身智能——语音→意图→运动控制全链路，差速底盘 + 编码器 PID

## 场景三：语音控制灯光（40s）

> 小智，把客厅灯调到 30%

- 灯节点 PWM 调光 → 亮度降至 30%
- 小智："好的，客厅灯已调到 30%。"

> 小智，把客厅灯调到 80%，颜色换成暖黄

- RGB 灯带变色
- 小智："客厅灯已调至 80%，暖黄色。"

**讲解点**：BLE 低功耗直连、参数抽取（亮度+色温双参数）

## 场景四：WiFi 联网控制空调（40s）

> 小智，空调调到 26 度

- WiFi 联网（MQTT/HTTP）控制空调（米家/Home Assistant 生态）→ 空调响应
- 小智："空调已设置为 26 度制冷。"

**讲解点**：参考米家智能家居模式，WiFi 联网通道统一控制主流智能设备

## 场景五：定点任务（40s）

> 小智，去卧室关灯

- 机器人移动到卧室门口（里程计 + 避障）
- BLE 控制卧室灯关闭 → 小智："已到卧室，灯已关闭。"

**讲解点**：移动 + 万物互联联动——"移动管家"完成跨空间任务

## 场景六：环境感知（30s）

> 小智，现在室温多少

- 传感器节点回读 → 小智："客厅当前 26.3 度，湿度 52%，空气质量良好，光照充足。"

**讲解点**：多传感器融合、状态回读闭环

## 场景七：场景联动（40s）

> 小智，执行睡眠模式

- 灯调暗 5% → 窗帘关闭 → 空调 26 度睡眠 → 插座断电
- 小智："睡眠模式已执行：灯光已调暗，窗帘已关闭，空调已设置为睡眠模式。"

**讲解点**：场景引擎，一条指令联动全屋

## 场景八：NAS 知识中枢（40s）

> 小智，明天上午有什么安排

- NAS 日历读取 → 小智："明天上午 9 点有毕设中期答辩，10 点半和导师约了讨论。"

> 小智，把"记得买牛奶"记到待办

- NAS 写入待办 → 小智："已记录：买牛奶。"

**讲解点**：私有数据中枢，数据主权，RAG 文档问答

## 场景九：主动智能（40s）

（等待或模拟温度升高）

- 小智主动移动到用户身边插话："检测到厨房温度偏高，疑似忘关火，已提醒并推送手机通知。"

**讲解点**：主动化——不是"你问它答"，而是"它替你着想"，且会移动到你身边

## 场景十：离线降级（20s）

- 断开 WiFi 演示
> 小智，打开客厅灯

- 本地命令词 → 灯点亮
- 小智："已切换到离线模式，客厅灯已打开。"

**讲解点**：断网可靠性，本地兜底

## 场景十一：视觉×语音联动（40s）

> 小智，门口是谁

- 摄像头拍照 → AI 识别 → 小智："门口是快递员，正在放包裹。"

**讲解点**：多模态，视觉+语音融合

## 答辩问答预备

| 可能的问题 | 参考回答 |
|---|---|
| 为什么选小智而非自研 | 小智是开源语音硬件标杆，聚焦"运动控制层/控制层/知识层/主动层"原创开发，避免重复造轮子 |
| 移动机器人怎么导航 | 编码器里程计 + 超声波避障 + IMU 航向校正，语音召唤用声音源定位，低成本室内移动方案 |
| BLE 怎么组网 | 终端作为 BLE Central 扫描节点（XZ-* 广播名）→ GATT 连接 → 特征值写入控制 |
| 断网怎么控制 | 离线命令词引擎：本地关键词匹配 + 设备映射，绕过云端 |
| 主动提醒误报怎么办 | 规则引擎可调阈值 + 多次采样确认 + 用户可关停单条规则 |
| 数据安全 | 个人数据仅存 NAS，MQTT 支持 TLS，声纹本地处理 |
| 扩展性 | 新增设备=新增节点/新增工具 schema，中枢架构天然可扩展 |
